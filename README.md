# Skincare Booking System

## Giới thiệu
Skincare Booking System là website hỗ trợ đặt lịch dịch vụ chăm sóc da, giúp khách hàng dễ dàng tìm kiếm và đặt lịch sử dụng dịch vụ trực tuyến.

## Công nghệ sử dụng
### Frontend
- HTML
- CSS
- Javascript
- Thymeleaf

### Backend
- Java Spring Boot
- Spring Security
- JWT Authentication
- MySQL

## Chức năng chính

### Người dùng
- Đăng ký / đăng nhập tài khoản
- Xem danh sách dịch vụ skincare
- Tìm kiếm và xem chi tiết dịch vụ
- Đặt lịch dịch vụ
- Theo dõi trạng thái booking
- Gửi feedback sau khi sử dụng dịch vụ

### Quản trị viên
- Quản lý dịch vụ skincare
- Thêm / sửa / xóa dịch vụ
- Upload hình ảnh dịch vụ
- Quản lý booking và trạng thái lịch hẹn
- Quản lý tài khoản người dùng và nhân viên
- Phân quyền người dùng

## Kiến trúc hệ thống
- DTO - Entity - Mapper - Service - Controller
- RESTful API
- Authentication & Authorization bằng JWT
